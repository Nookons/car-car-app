# Рыночные метрики объявления

Таблица `listing_market_metric` — одна текущая строка на объявление. Это тот
слой, который отвечает на вопрос «сколько стоит эта машина относительно рынка
и как быстро уходят похожие».

## Что считается

| Блок | Поля | Источник |
|---|---|---|
| Цена | `estimate`, `base_median`, `price_p10/p90`, `diff_pct`, `verdict` | `analyse_price` по активным аналогам |
| Похожесть | `active_count`, `used_count`, `avg_similarity` | активные аналоги, до 60 на объявление |
| Снятые | `off_market_count`, `sold_candidate_count`, `dom_p25/median/p75`, `dom_sample` | `listing_lifecycle`, только не-`legacy`, `detection_lag_days <= 1` |
| Качество | `confidence`, `flags`, `stage` | размер выборки, наличие DOM |
| Аудит | `report` (JSONB) | критерии и аналоги из `analyse_price` + lifecycle |

`dom_*` считаются **только по `sold_candidate`**. Если продаж-кандидатов нет
(сейчас их почти нет), `dom_median = NULL`, `flags` содержит `no_dom`, а
уверенность не выдаётся выше `medium`. Это честнее, чем показывать 30-дневное
истечение как «срок продажи».

## Два этапа

- `preliminary` — сразу после вставки нового объявления из выдачи (watch).
  Есть цена, год, пробег, топливо, КПП; нет кузова/цвета/комплектации.
- `final` — после загрузки карточки (`fetch_detail`). Появляются кузов, цвет,
  drive, generation, equipment; метрика пересчитывается.

## Вызов

Автоматически:

- `discover()` после вставки новых объявлений вызывает
  `analyze_external_ids(..., stage="preliminary")`;
- `fetch_detail()` после обновления карточки — `stage="final"`.

Вручную:

```bash
python -m carcar market-metrics --limit 50 --stage final
python -m carcar market-metrics --listing-id 465647 --stage final
```

Ошибка метрик не блокирует публикацию: в `discover` она ловится и пишется в лог.

## Ограничения

- `sold_candidate` — эвристика (цена вниз перед снятием), не подтверждённая
  сделка.
- `legacy`-снятые исключены: у них даты восстановлены задним числом.
- `detection_lag_days > 1` исключён: дата снятия ненадёжна.
- Таблица хранит только текущий срез; истории пересчётов нет.
- Бэкфилл всех 265k активных не делается автоматически: это отдельная
  нагрузка, запускать через `--limit` порциями.
