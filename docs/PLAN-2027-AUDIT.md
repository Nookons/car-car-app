# CarCar против плана 2027: аудит и рабочий срез

Дата: 12.11.2026. Основание: [`CarCar-plan-2027.pdf`](../plan/CarCar-plan-2027.pdf)
(15 страниц, декабрь 2026 — ноябрь 2027).

Документ отвечает на два вопроса: что из плана уже есть в приложении и что
делаем первым. Приоритет — раздел плана «Первые 14 дней»: без воронки,
онбординга и шортлиста остальные кварталы нечем измерять.

> Таблицы 3.x фиксируют состояние **до** этого среза. Что уже реализовано —
> раздел 4; после него воронка, онбординг, шортлист, share/inline и RODO-страницы
> есть в коде.

## 1. Короткий вывод

Приложение сильнее плана в **данных и карточке**: есть полный рынок otomoto,
история цены, оценка рынка, Telegram-бот, Mini App, веб-вход, четыре языка.
Но оно слабее плана в **активации и удержании**: новый человек попадает в
пустой поиск без онбординга, избранное — плоский список без статусов, нет
событий воронки, share-карточки и inline-бота, а юридические страницы и
удаление аккаунта отсутствуют, хотя план требует их «сейчас».

Поэтому фокус этого среза — не новые источники и не монетизация, а путь
`визит → поиск → сохранённый поиск → алерт` и первый пользовательский
артефакт — шортлист.

## 4. Приоритет работ

### Реализовано в этом срезе (12.11.2026)

1. `funnel_event` + `POST /api/events` + `GET /api/admin/funnel` + экран.
2. Онбординг `/onboarding` (3 шага, сохранённый поиск, демо-алерт).
3. Шортлист: статусы `shortlist/contacted/viewed/rejected/bought` и заметка.
4. `/share/[id]` + OG-картинка + `inline_query` в боте.
5. `/privacy`, `/terms`, удаление аккаунта и экспорт данных.

Проверено: `pytest` (весь набор), `ruff`, `tsc --noEmit`, `next build`;
живой smoke на Supabase — события воронки, шортлист, демо-алерт, экспорт,
удаление аккаунта; OG-картинка и share-страница отдаются с фронта.

### Следующие срезы

1. OLX/Allegro/AutoScout24 — по одному, с контрактным тестом.
2. Weekly pulse, CTR алерта, тест алерта в боте.
3. Импорт ссылки и сравнение.
4. SEO v1: модели, цены, проверка, импорт.
5. Расширение Chrome.

## 5. Метрики, которые теперь можно считать

| Метрика плана | Как считается |
|---|---|
| Визиты | `funnel_event kind=visit`, уникальные `visitor_id` |
| Поиски | `kind=search`, уникальные visitor/user |
| Сохранённые поиски | `kind=saved_search` |
| Алерты | активные `subscription` + `kind=alert_open` |
| Активация 7 дней | пользователь с `saved_search` или `favorite_add` за 7 дней |
| D7/D30 | по `user_activity_daily` и `funnel_event` |
| MAU | `user_activity_daily` |
| Шортлист | `favorite.status` |
| CTR алерта | `alert_open` / отправленные уведомления (следующий срез) |

Клиентские события не хранят IP или заметки. Запросы авторизованных
пользователей отдельно сохраняются с фразой и фильтрами, доступны в карточке
пользователя и экспорте, удаляются при удалении аккаунта и очищаются через
400 дней.
