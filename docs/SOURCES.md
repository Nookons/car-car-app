# Источники данных: что реально отдаётся (разведка 05.11.2026)

Все проверки сделаны с этой машины обычным `curl`/`urllib`: браузерный User-Agent,
`Accept-Language: pl-PL`, без куков, без прокси, без выполнения JS.
Скрипт-повторитель: `scripts/probe_otomoto.py`.

## otomoto.pl — основной источник

### Что проверено

```
GET https://www.otomoto.pl/osobowe?search[order]=created_at:desc
→ 200, HTML 1.73 МБ, 1.6–2.0 с, 32 объявления на страницу
→ totalCount = 257 382
```

- Сайт на Next.js: **вся выдача поиска уже лежит в HTML** внутри
  `<script id="__NEXT_DATA__">` → `props.pageProps.urqlState` (состояние
  GraphQL-клиента urql, отрендеренное на сервере).
- Никакого браузера, JS, куков и прокси не требуется — обычный GET.
- `pageSize = 32`, пагинация `&page=N`.
- Сортировка `search[order]=created_at:desc` работает **не строго**. Замер
  (3 страницы, 98 объявлений): 50 штук — сегодняшние, но на первой странице
  **13 из 32 старше суток** (10.10–30.10), вперемешку со свежими; метка
  `isPremiumTopAd` при этом почти везде `null`. Это «поднятые»/продвигаемые
  объявления: дата старая, позиция верхняя.
  Вывод для сборщика: нельзя останавливаться «на первом знакомом id» и нельзя
  резать по `createdAt` — пропустим свежие, стоящие ниже поднятого.
  Правило: 2 страницы подряд, где >90% id уже известны.
- Темп появления новых: ~3–4 объявления в минуту в рабочее утро → порядка
  **3–6 тыс. новых в сутки**.
- Фильтры живут в URL и работают:
  `search[filter_float_price:to]=30000` → `totalCount = 78 446`.
  Значит можно обходить рынок не целиком, а когортами (марка/модель/цена/регион).

### Поля выдачи (одно объявление)

`id, title, createdAt, shortDescription, url, badges, isPremiumTopAd, category,
location{city, region}, thumbnail{x1,x2}, price{amount{value,currencyCode}},
parameters[{key,value,displayValue}], seller{__typename,...}, priceDrop,
originAdId, originSiteCode, cepikVerified`

`originAdId` / `originSiteCode` — признаки кросс-постинга (то же объявление
пришло с другой площадки группы OLX). Пригодится для дедупликации между
источниками.

### Поля карточки объявления

```
GET https://www.otomoto.pl/osobowe/oferta/<slug>-ID<hash>.html
→ 200, HTML 0.76 МБ, advert в pageProps
```

| Поле | Что внутри | Зачем |
|---|---|---|
| `details[]` | make, model, version, generation, year, **vin**, fuel_type, engine_capacity, engine_power, body_type, gearbox, transmission, mileage, color, doors, seats, country_origin, co2, registration, no_accident, service_record, vat_discount | нормализация, фильтры, аналитика |
| `description` | HTML, ~1.5 тыс. символов (в примере) | поиск по тексту, VIN, комплектация |
| `images.photos[]` | 37 фото в примере, CDN `ireland.apollo.olxcdn.com` | карточка, перцептивный хэш для дедупа |
| `seller` | type PROFESSIONAL/PRIVATE, name, sellerUrl, бейджи, пакет | дилер vs частник |
| `price` | value, currency, labels (`negotiable`) | история цен |
| `createdAt`, `updatedAt`, `originalCreatedAt` | даты | «сколько висит», перевыставления |
| `priceDrop` | данные о снижении цены | алерт «упала цена» |
| `equipment[]` | 49 пунктов в примере, по группам | фильтры «климат/кожа/навигация» |
| `phoneNumbers` | зашифрованы, расшифровываются на клиенте | **не трогаем** |

**VIN есть не всегда** (`—` в примере): заполняется продавцом добровольно.
Значит дедупликация не может опираться только на VIN.

### robots.txt (важно для легальности)

```
User-agent: *
Disallow: /adminpanel/  /authentication*  /catalog/*/*/  */rss/
Disallow: /ad2/  /ad/leaflet/  /ad/contact/  /payment/  /i2/  /pwa/
Disallow: /ajax/  /api/  /parts-listing-poc*  ...
Allow: /
Content-Signal: ai-train=yes, search=yes, ai-input=yes
```

Читаем так: **страницы выдачи и карточек — разрешены** (`Allow: /`), а
`/api/` и `/ajax/` — запрещены. Мы и не используем API: забираем те же данные
из HTML-страниц, которые робот разрешает. `Content-Signal: search=yes` —
площадка явно не против индексации и поиска по своим страницам.

### Объём и стоимость обхода

- 257 382 / 32 = **8 044 страницы** ≈ **13.7 ГБ HTML** ≈ **2.2 ч** при 1 req/s.
- Парсинг — узкое место не CPU (json.loads страницы ~20–30 мс), а сеть.
- Полный обход нужен для аналитики цен (медианы по когортам) — раз в сутки/неделю.
- Инкремент: раз в 2–3 минуты 1–2 страницы (`created_at:desc`) — ~700 запросов/сутки.

## olx.pl — почему отложен

```
GET https://www.olx.pl/            → 403 (CloudFront: "Request blocked")
GET https://www.olx.pl/robots.txt  → 403
```

Блокировка отдаётся на уровне CDN ещё до приложения — по IP/UA/отпечатку.
Это не «страница изменилась», а активная защита. Варианты, когда дойдём:

1. Playwright + настоящий браузер (медленно: ~2–5 с на страницу, ресурсы);
2. резидентный прокси (€5–15/мес за трафик);
3. официальный доступ: у OLX Group есть партнёрские API/фиды для дилеров —
   для агрегатора это самый чистый путь, но требует переговоров.

**Обходить защиту (капчи, отпечатки) не будем** — это уже не «открытые данные»,
а взлом технических средств защиты. Если площадка не пускает — идём через
официальный канал или не берём её.

## allegro.pl — только официальный API

`allegro.pl` отдаёт 403 (защита). Но у Allegro есть публичный REST API
(`developer.allegro.pl`) с OAuth2: поиск предложений, категории, параметры.
Регистрация приложения бесплатная, лимиты — 9000 запросов/мин на приложение
(на практике ограничивает сам эндпоинт). Автомобили на Allegro — это в основном
дилерские объявления и запчасти; как второй источник — средне приоритетный,
но интеграция чистая, без скрейпинга.

## autoscout24.pl

Отдаёт 200, Next.js с `__NEXT_DATA__`, но SSR-выдача пустая
(`numberOfResults: 0`, `listings: []`): список тянется отдельным API под
Akamai-защитой. Для Польши объём небольшой — не приоритет.

## Что это значит для плана

1. **Старт — otomoto.** Один источник, но 257 тыс. объявлений и полные
   структурированные поля: этого хватает и на MVP, и на аналитику цен.
2. **Второй источник — OLX**, но только после того, как отработает первый:
   он дороже по инфраструктуре (браузер/прокси) и юридически чувствительнее.
3. **Дедупликация между площадками** проектируется сразу (VIN + перцептивный
   хэш фото + отпечаток), даже когда источник один: дилеры кросс-постят.
4. **Контрактные тесты на фикстурах.** Структура `__NEXT_DATA__` может
   измениться в любой день; ломаться должно тестом, а не тишиной в проде
   («0 объявлений» = алерт).
